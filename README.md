# xss-sqli-phishing-with-ML
building an Intrusion Detection System (IDS) that detects:
-XSS attacks
-SQL Injection (SQLi)
-Phishing URLs
Using Machine Learning.

Pipeline:
Traffic / URL / Payload
        ↓
Feature Extraction
        ↓
ML Model (trained)
        ↓
Attack Type Detection
        ↓
Alert / Log / Dashboard
